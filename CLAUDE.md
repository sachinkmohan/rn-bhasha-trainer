# rn-bhasha-trainer

**Bhasha Sakhi** — an Expo / React Native app for practising Malayalam pronunciation, built around confusable word pairs (retroflex vs. regular consonants, minimal vowel differences). It is **live on the Google Play Store** as `com.bhashasakhi.app`, so release-affecting changes carry real store-policy consequences, not hypothetical ones.

Things that aren't obvious from the folder names:

- **Offline-first, no backend.** All user progress lives in a single AsyncStorage key, `pronunciation_practice_data` (`utils/storage.ts`). There is no server and no account system today.
- **Word content is UUID-keyed.** `wordsMalayalam.json` is the source of truth for words; `data/confusablePairs.ts` references them by those UUIDs, and stored progress is keyed on them too. **Never regenerate or renumber word `id`s** — doing so silently orphans every existing user's progress. See `docs/WORD_UUID_REFERENCE.md`.
- **Two app variants.** `app.config.ts` switches bundle id, name, and scheme on `APP_VARIANT`. Use `npm run dev` (which sets `APP_VARIANT=development` → `com.bhashasakhi.app.dev`) rather than bare `expo start` when testing against the dev client.
- **`lessons/` and `learning-records/` are not app content.** They're personal teaching notes about this codebase generated by the `/teach` skill. Don't ship, import, or refactor them alongside app code.
