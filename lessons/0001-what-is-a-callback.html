Lesson 0001 · Callbacks

What Is a Callback?

A callback is nothing more than: a function, handed to another piece of code as an argument, which that other code calls at the right moment. The function doesn't run immediately when you pass it — it runs later, whenever the receiver decides to invoke it.

Primary source: MDN — Callback function

The smallest possible example:

function greet(name, onDone) {
  console.log("Hi " + name);
  onDone(); // <- the receiver decides when to call it
}

greet("Sachin", () => console.log("greeting finished"));

onDone is a callback. greet didn't define what it does — the caller of greet did. greet just promised to call it at some point.

Not every function on that screen is a callback prop

player.play() is different — player comes back from the useWordAudio() hook, and .play() is a method that hook's return value exposes. Nobody "handed" play to AudioPlayer as a prop; it's part of the object the hook returned. Same surface shape (a function you call), different relationship.
